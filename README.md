# README — ПР №8: Игровое приложение WPF «Поймай квадрат»

---

## 1. Цель работы

Изучить и продемонстрировать разработку интерактивного игрового приложения на платформе **WPF**: работу с графическими элементами (`Canvas`, `Rectangle`), обработку событий клавиатуры (`KeyDown` / `KeyUp`), организацию игрового цикла через `DispatcherTimer`, а также отделение игровой бизнес-логики в самостоятельный класс `GameManager`. Освоить обработку пользовательских действий с подтверждающими сообщениями и корректную обработку исключительных ситуаций.

---

## 2. Описание проекта

**Название:** «Поймай квадрат» (CatchTheSquare)

**Назначение:** Учебное десктопное приложение-игра, в которой пользователь управляет синим квадратом-игроком с клавиатуры и должен «поймать» красный квадрат-цель. При каждом столкновении начисляется очко, а цель перемещается в случайную точку. Игра отслеживает текущий счёт и прошедшее время.

**Демонстрируемый подход:** Разделение представления (WPF-разметка и code-behind) и бизнес-логики (`GameManager`) по принципу MVC-подобного разделения ответственности. Игровой цикл реализован через событийную модель WPF (`DispatcherTimer.Tick`). Управление состоянием игры (запущена / пауза / сброшена) осуществляется через флаги `_isGameRunning`, `_isPaused`, `_hasStarted`.

**Технологии:** C#, WPF, .NET 6/7/8 (или .NET Framework 4.7.2+).

## 3. Функциональность

| № | Кнопка / элемент | Действие |
|---|---|---|
| 1 | **Начать игру** | Сбрасывает счёт и время, показывает игрока и цель, размещает их на `Canvas`, запускает `DispatcherTimer`, выводит MessageBox с текущим счётом |
| 2 | **Пауза** | Приостанавливает игровой цикл, выводит сообщение с текущим счётом |
| 3 | **Продолжить** | Возобновляет игру; если игра не была запущена — показывает предупреждение |
| 4 | **Сбросить игру** | Останавливает таймер, очищает `Canvas`, обнуляет счёт и время, выводит сообщение |
| 5 | **Показать правила** | Открывает диалоговое окно `RulesWindow` с инструкцией |
| 6 | **Выход** | Завершает работу приложения (`Application.Current.Shutdown()`) |
| 7 | **Управление (стрелки / WASD)** | Перемещает игрока по полю с шагом 15 px; удержание клавиши — плавное движение |
| 8 | **Счёт (`TextBlock`)** | Обновляется при каждом столкновении с целью |
| 9 | **Время (`TextBlock`)** | Увеличивается раз в секунду, пока игра активна |
| 10 | **Автоматическое столкновение** | При пересечении игрока и цели начисляется +1 очко, цель перемещается в случайную позицию |

## 4. Архитектура / реализация

### Структура проекта

```
CatchTheSquare/
├── App.xaml / App.xaml.cs          — точка входа приложения
├── MainWindow.xaml / .xaml.cs      — главное окно, UI и игровой цикл
├── GameManager.cs                  — бизнес-логика игры
└── RulesWindow.xaml / .xaml.cs     — диалоговое окно с правилами
```

### Схема взаимодействия

```
┌──────────────────────────────┐
│        MainWindow            │
│  (View + Controller)         │
│                              │
│  Canvas (GameCanvas)         │
│   ├── Rectangle PlayerRect   │
│   └── Rectangle TargetRect   │
│                              │
│  DispatcherTimer _timer ─────┼──► Timer_Tick()
│  KeyDown / KeyUp             │        │
│  Buttons: Start/Pause/...    │        │
└──────────────┬───────────────┘        │
               │ вызывает               │
               ▼                        ▼
        ┌─────────────────────────────────┐
        │          GameManager            │
        │  - int _score                   │
        │  - int _timeElapsed             │
        │  + Score { get; }               │
        │  + TimeElapsed { get; }         │
        │  + AddScore(int)                │
        │  + Tick()                       │
        │  + ResetGame()                  │
        │  + CheckCollision(...)          │
        └─────────────────────────────────┘
```

### Ключевые элементы

- **`MainWindow`** — представление и контроллер. Хранит ссылки на визуальные объекты (`PlayerRect`, `TargetRect`), управляет таймером и клавиатурным вводом.
- **`GameManager`** — «чистая» бизнес-логика, не зависящая от UI. Хранит счёт и время, умеет проверять столкновения и сбрасывать состояние.
- **`DispatcherTimer`** — источник игрового цикла. Интервал `30 мс` обеспечивает плавное движение; счётчик тиков (`_tickCounter`) используется для инкремента времени раз в секунду.
- **`RulesWindow`** — модальное окно с инструкцией (открывается через `ShowDialog()`).
- **`_pressedKeys`** (`HashSet<Key>`) — множество одновременно нажатых клавиш для поддержки плавного диагонального движения.

## 5. Бизнес-логика (`GameManager`)

| Метод / свойство | Описание |
|---|---|
| `int Score { get; }` | Возвращает текущее количество очков |
| `int TimeElapsed { get; }` | Возвращает прошедшее игровое время в секундах |
| `void AddScore(int points)` | Увеличивает счёт на `points`; бросает `ArgumentOutOfRangeException` при отрицательном значении |
| `void Tick()` | Инкрементирует `TimeElapsed` на 1 (вызывается раз в секунду из таймера) |
| `void ResetGame()` | Обнуляет счёт и время |
| `bool CheckCollision(playerX, playerY, targetX, targetY, size)` | Проверяет пересечение двух квадратов через AABB-тест: `pX < tX + s && pX + s > tX && pY < tY + s && pY + s > tY` |

## 6. Особенности реализации

- **Разделение ответственности.** `GameManager` не знает о WPF — легко покрывается модульными тестами.
- **Обработка состояний игры.** Три флага — `_isGameRunning` (активен ли таймер), `_isPaused` (приостановлен ли), `_hasStarted` (запускалась ли игра хоть раз) — позволяют корректно реагировать на все комбинации нажатий кнопок.
- **Обработка исключительных ситуаций.** Попытка «Продолжить» без старта выдаёт `MessageBox` с предупреждением; запуск игры обёрнут в `try/catch`, ошибка показывается пользователю.
- **Подтверждающие сообщения.** После старта, паузы, продолжения и сброса выводится `MessageBox` с актуальным счётом (пример: «Игра началась. Текущий счёт: 0»).
- **Плавное управление.** Используется `HashSet<Key>` нажатых клавиш — движение обрабатывается в тике таймера, а не по одному событию, что позволяет удерживать клавишу и двигаться диагонально.
- **Ограничение движения по границам `Canvas`.** Позиция игрока клипуется в диапазоне `[0, ActualWidth - SquareSize]` / `[0, ActualHeight - SquareSize]`.
- **Инициализация фокуса.** В `Loaded` вызывается `Keyboard.Focus(this)` — иначе `KeyDown` не срабатывает, пока пользователь не кликнет по окну.
- **Потокобезопасность.** Все операции выполняются в UI-потоке (`DispatcherTimer` работает в UI-потоке), поэтому дополнительная синхронизация не требуется.

## 7. Требования и запуск

**Требования:**
- .NET SDK 6.0 / 7.0 / 8.0 (или .NET Framework 4.7.2+)
- Visual Studio 2022 / Rider (или CLI `dotnet`)
- Windows (WPF)

**Сборка и запуск:**

```bash
# Восстановление зависимостей и сборка
dotnet build

# Запуск приложения
dotnet run

# Публикация (опционально)
dotnet publish -c Release -r win-x64 --self-contained false
```

Или открыть `CatchTheSquare.csproj` в Visual Studio и нажать **F5**.

**Использование:**
1. Нажмите «Начать игру».
2. Управляйте синим квадратом стрелками или клавишами `W/A/S/D`.
3. Догоняйте красный квадрат — за каждое столкновение +1 очко.
4. Используйте «Пауза» / «Продолжить» / «Сбросить игру» по необходимости.
